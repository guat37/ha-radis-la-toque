# Politique de sécurité

Pour une vulnérabilité de sécurité, évitez de publier immédiatement des détails exploitables dans une issue publique. Contactez le mainteneur du dépôt via les mécanismes privés proposés par GitHub (Security Advisories) lorsque le dépôt sera publié.

L'intégration ne gère aucun secret fournisseur : les menus utilisés sont publics et accessibles sans authentification.
