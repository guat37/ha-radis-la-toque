# Branding

L'icône du projet est une création originale : assiette, couverts et pousse végétale. Elle ne reprend ni le personnage, ni le logo, ni les pictogrammes de RESTORIA/Radis la Toque.

Fichiers embarqués :

- `custom_components/radis_la_toque/brand/icon.png` — 256×256 PNG RGBA ;
- `custom_components/radis_la_toque/brand/icon@2x.png` — 512×512 PNG RGBA.

Home Assistant 2026.3+ sait charger directement les brand images d'une custom integration depuis le dossier `brand/`.
